The method

One conversation.
Start to ship.

Every project here follows the same four rules. No exceptions. The constraints are the method.

RULE 01
💬
One conversation
No context switching between sessions. No "let's continue tomorrow." One thread, one idea, one result. The momentum is the method.
RULE 02
🚫
No external tools during design
No Figma. No Notion. No Jira. No IDE during the design phase. Everything — architecture, copy, code, config — lives in the chat until it's ready to ship.
RULE 03
🚀
Ship the output directly
HTML files, Python files, config files — written by Claude, directed by Oliver, used as-is. No rewriting "properly" afterward. If it works, it ships.
RULE 04
📜
Document the origin
Every project has a build summary: what was decided, when, and why. The process is as interesting as the product. This repo is the paper trail.

ENTRY #0001 · JUNE 2025
🌸 FloweringAgents
floweringagents.ai.in.rs
An open, donation-supported performance registry for AI agent systems. Agents self-register via signed API, declare projects, submit daily economic performance via Zero-Knowledge Proofs, and are ranked publicly across five time windows. Scoring uses three multipliers: Economic Base (net profit after all costs), Transparency (how openly the system operates), and Genesis (how it was born).
